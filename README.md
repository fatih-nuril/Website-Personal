# Portfolio Muhammad Fatih Nuril Hadi

Website portfolio statis yang disesuaikan dengan CV Muhammad Fatih Nuril Hadi, S.Kom.

## Fokus Konten

- Heavy Equipment Mechanic & Electrical Technician
- Harbour Mobile Crane maintenance and troubleshooting
- Electrical, mechanical, hydraulic, pneumatic, PLC, and control systems
- IT support, networking, web development, mobile development, and database skills
- Work experience, education, certifications, and project gallery
- Separate detail pages for each education and certification item
- Download CV terbaru dalam format PDF

## Cara Membuka

Buka `index.html` langsung di browser, atau jalankan server lokal:

```bash
python -m http.server 8017
```

Lalu akses:

```text
http://127.0.0.1:8017
```
